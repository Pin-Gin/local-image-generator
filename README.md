# local-RAG

Local Windows image-generation application with two independent generation domains:

- **FREE** — natural-language / JSON driven text2img, without MEMORIELA-specific assets.
- **MEMORIELA** — named-character production generation with modular character/outfit/situation/background assets.

Both domains share the same `Matte Dimensional Anime` rendering layer. The rendering layer supports prompt rules now and a locally trained rendering LoRA when activated.

Start with [`START_HERE.md`](START_HERE.md).

Rendering learning is documented in [`learning/rendering/README.md`](learning/rendering/README.md).
