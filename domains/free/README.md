# FREE generation domain

FREE is the unrestricted text/JSON generation path.

Rules:
- input is natural language or JSON;
- no MEMORIELA character MASTER, outfit asset, character LoRA, situation asset, or background authority is injected;
- generation should reproduce the user's specified content as directly as possible;
- the only shared visual dependency is the shared rendering layer under `shared/rendering/`;
- FREE must remain independent from MEMORIELA-specific training assets.
